# Як обробляти запис

Користувач дає файл і каже щось на кшталт «ось запис, оброби його». Відповідай мовою користувача. Порядок:

1. Перевір `ffmpeg` і `uv`. Немає: на Mac `brew install ffmpeg uv`.
2. Немає `.venv` у корені репозиторію: `uv venv --python 3.12 .venv`, потім `VIRTUAL_ENV=$PWD/.venv uv pip install -r requirements.txt`. Перший раз це кілька хвилин, torch важить понад гігабайт: попередь користувача.
3. Звіт без рендеру: `.venv/bin/python smart_edit.py <вхід> <вихід> --enhance-audio --language uk --whisper-model small`. Вихідний файл клади поруч із вхідним, із суфіксом `-edited.mp4`.
4. Покажи коротко: скільки триває запис зараз, скільки стане, які дублі викидаються і як читаються шви.
5. Користувач казав «кат-кат», а мітку не знайдено: повтори звіт із `--marker-isolation 0.3`.
6. Запис ширший за 4096 пікселів (наприклад 5K запис екрана): додай `--scale 2560:1440`, інакше апаратний кодер Mac віддасть порожній файл.
7. Після «ок» запусти ту саму команду з `--apply`.
8. Хоче коротше: запропонуй прискорення на 10% командою з README.

Без підтвердження нічого не рендери. Вхідний файл не змінюй і не видаляй.
