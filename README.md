# video-autoedit

Автомонтаж відео з голосом: вирізає паузи, викидає зіпсовані дублі за міткою «кат-кат» і вирівнює звук. Скрипт до виступу Даніла Кладова на Open Microphone у Sales Mates Library, 30.10.2026.

## Найпростіше: попросіть Claude Code

Відкрийте [Claude Code](https://claude.com/claude-code) і скажіть:

> Склонуй github.com/tailored-tech-ai/video-autoedit. Ось запис ~/Downloads/video.mp4, оброби його.

Claude прочитає інструкцію в `CLAUDE.md`, сам поставить ffmpeg і Python, покаже звіт, що буде вирізано, і відрендерить після вашого «ок». Перший запуск займає кілька хвилин: бібліотека torch важить понад гігабайт.

Перевірено на Mac.

## Протокол запису

Скрипт ріже за мітками, які ви ставите голосом під час запису.

1. **Перед кожним блоком пауза дві секунди.** Мовчки, вдих, почав. Ця пауза стає точкою, куди відкочується монтаж.
2. **Блок це одна думка, два-чотири речення.** Стільки, скільки готовий переписати повністю.
3. **Збився: фразу не рятуєш.** Стоп, секунда тиші, вголос «кат-кат», ще секунда, звичайна пауза і весь блок заново тими самими словами. Тиша з обох боків мітки обов'язкова: з паузою в пів секунди скрипт мітку не чує.
4. **Не починай заново з середини речення.** Інакше незрозуміло, куди відмотувати.

## Що робить скрипт

- Знаходить мову нейромережею Silero VAD і вирізає паузи, довші за пів секунди.
- Шукає «кат-кат» лише в коротких відрізках між паузами і викидає все від попередньої паузи у дві секунди до мітки включно.
- З `--enhance-audio` обробляє звук: зрізи нижче 80 Гц і вище 12 кГц, легкий еквалайзер, м'яка компресія, нормалізація до -16 LUFS.
- Без `--apply` нічого не рендерить, лише показує звіт.

На демо до виступу 2:36 запису стали 1:40, після прискорення на 10% 1:32.

## Вручну

Потрібні Python 3.12 і ffmpeg.

```bash
brew install ffmpeg uv
uv venv --python 3.12 .venv
VIRTUAL_ENV=$PWD/.venv uv pip install -r requirements.txt
```

Звіт без рендеру:

```bash
.venv/bin/python smart_edit.py input.mp4 output.mp4 --enhance-audio --language uk --whisper-model small
```

Рендер: та сама команда з `--apply`.

| Прапорець | Навіщо |
|---|---|
| `--marker "кат кат"` | своя мітка |
| `--checkpoint-gap 2.0` | пауза, до якої відкочується монтаж від мітки |
| `--marker-isolation 0.3` | мітку сказано з короткою паузою, і скрипт її не знайшов |
| `--cut 28.1-64.2` | ручний різ у секундах, можна кілька разів |
| `--scale 2560:1440` | запис ширший за 4096 пікселів: апаратний кодер Mac інакше віддає порожній файл |
| `--speed 1.1` | прискорення на 10% у тому ж рендері |

**Прискорення.** `--speed` прискорює відео через `setpts`, звук через `atempo`, тембр голосу не змінюється. Допустимо від 0.5 до 2.0. Окремий прохід ffmpeg потрібен лише для вже готового файлу, він кодує відео вдруге:

```bash
ffmpeg -i output.mp4 -filter_complex "[0:v]setpts=PTS/1.1[v];[0:a]atempo=1.1[a]" -map "[v]" -map "[a]" output-fast.mp4
```

## Конвеєр із Tight Studio

`tight_publish.py` доводить проєкт Tight Studio до готового mp4 однією командою, без кліків в інтерфейсі:

1. Відкриває проєкт у фоні, фокус лишається у вас.
2. Розшифровує запис і вмикає субтитри.
3. Вичитує субтитри: прибирає «е-е-е» й обірвані слова, ставить розділові знаки, виправляє імена й терміни за словником `captions-glossary.txt`. Запобіжник відкидає правку, де з'явилося слово, якого не було в записі, або зникло справжнє. Час слів після правки відновлюється, підсвітка слів не з'їжджає.
4. Розмиває адресний рядок і закладки браузера. Текст на кадрах розпізнає вбудований у macOS Vision, без мережі. Маски стають у проєкт Tight Studio і їдуть разом із зумом.
5. Експортує MP4 і запускає `smart_edit.py`: паузи, «кат-кат», прискорення.
6. Звук: голосова обробка, фонова музика без розривів на склейках, гучність -16 LUFS у два проходи.

### Налаштування

Потрібні Mac, Tight Studio з розширенням для Claude Desktop і Claude Code. Перевірено на Tight Studio 3.2.5.

Відкрийте Claude Code у теці репозиторію і скажіть:

> Налаштуй конвеєр Tight Studio під мою машину.

Claude перевірить і поставить ffmpeg, uv, node і Python-оточення, збере дві маленькі програми на Swift, допише ваші імена й терміни в словник і збереже ваші налаштування (мова, музика, прискорення) у `tight_publish.local.json`. Руками лишається те, що просить пароль або клік у системному вікні: Homebrew, Xcode Command Line Tools і доступ для TightClick.

### TightClick

Два вікна Tight Studio через його API не закрити: Allow, коли скрипт підключається після запуску Tight Studio, і вибір теки з кнопкою Export here під час експорту. Їх натискає TightClick, міні-програма з `tightclick/`, яка вміє лише ці дві кнопки. Доступ Accessibility отримує тільки вона. Видати його терміналу означало б дати кожній команді в ньому, зокрема чужим install-скриптам, клікати й друкувати в будь-якій програмі. Без TightClick конвеєр працює так само, ці два кліки робите ви.

### Запуск

```bash
.venv/bin/python tight_publish.py "назва проєкту"
```

Готовий файл `<назва експорту> final.mp4` лежить поруч з експортом. На кілька секунд Tight Studio виходить на передній план: експорт працює лише з вікна у фокусі.

| Прапорець | Навіщо |
|---|---|
| `--language uk` | мова запису для мітки й вичитки: uk, ru, en |
| `--music "назва"` | фонова музика з медіатеки Tight Studio, досить частини назви |
| `--music-volume 0.1` | гучність музики, 0.1 це 10% |
| `--speed 1.0` | без прискорення, за замовчуванням 1.1 |
| `--resolution 1080p` | роздільність експорту, за замовчуванням 4k |
| `--no-caption-check`, `--no-blur` | без вичитки субтитрів, без розмиття |
| `--export файл.mp4` | почати з готового експорту, без Tight Studio |
| `--save` | зберегти проєкт Tight Studio після конвеєра |

Свої значення за замовчуванням лежать у `tight_publish.local.json`, ключі як у прапорців. Вичитку й розмиття можна запустити окремо на відкритому проєкті: `caption_check.py` і `blur_browser.py`. Без `--apply` вони лише показують знайдене.
