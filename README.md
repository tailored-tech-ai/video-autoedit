# video-autoedit

Автомонтаж відео з голосом: вирізає паузи, викидає зіпсовані дублі за міткою «кат-кат» і вирівнює звук. Скрипт до виступу Даніла Кладова на Open Microphone у Sales Mates Library, 30.10.2026.

Відкрийте [Claude Code](https://claude.com/claude-code) і скажіть:

Claude прочитає інструкцію в `CLAUDE.md`, сам поставить ffmpeg і Python, покаже звіт, що буде вирізано, і відрендерить після вашого «ок». Перший запуск займає кілька хвилин: бібліотека torch важить понад гігабайт.

Перевірено на Mac.

## Протокол запису

Скрипт ріже за мітками, які ви ставите голосом під час запису.

1. **Перед кожним блоком пауза дві секунди.** Мовчки, вдих, почав. Ця пауза стає точкою, куди відкочується монтаж.
2. **Блок це одна думка, два-чотири речення.** Стільки, скільки готовий переписати повністю.
3. **Збився: фразу не рятуєш.** Стоп, секунда тиші, вголос «кат-кат», ще секунда, звичайна пауза і весь блок заново тими самими словами. Тиша з обох боків мітки обов'язкова: з паузою в пів секунди скрипт мітку не чує.
4. **Не починай заново з середини речення.** Інакше незрозуміло, куди відмотувати.

## Що робить скрипт

- Знаходить мову нейромережею Silero VAD і вирізає паузи, довші за пів секунди.
- Шукає «кат-кат» лише в коротких відрізках між паузами і викидає все від попередньої паузи у дві секунди до мітки включно.
- З `--enhance-audio` обробляє звук: зрізи нижче 80 Гц і вище 12 кГц, легкий еквалайзер, м'яка компресія, нормалізація до -16 LUFS.
- Без `--apply` нічого не рендерить, лише показує звіт.

На демо до виступу 2:36 запису стали 1:40, після прискорення на 10% 1:32.

## Вручну

Потрібні Python 3.12 і ffmpeg.

```bash
brew install ffmpeg uv
uv venv --python 3.12 .venv
VIRTUAL_ENV=$PWD/.venv uv pip install -r requirements.txt
```

Звіт без рендеру:

```bash
.venv/bin/python smart_edit.py input.mp4 output.mp4 --enhance-audio --language uk --whisper-model small
```

Рендер: та сама команда з `--apply`.

| Прапорець | Навіщо |
|---|---|
| `--marker "кат кат"` | своя мітка |
| `--checkpoint-gap 2.0` | пауза, до якої відкочується монтаж від мітки |
| `--marker-isolation 0.3` | мітку сказано з короткою паузою, і скрипт її не знайшов |
| `--cut 28.1-64.2` | ручний різ у секундах, можна кілька разів |
| `--scale 2560:1440` | запис ширший за 4096 пікселів: апаратний кодер Mac інакше віддає порожній файл |

Прискорення на 10%, тембр голосу не змінюється:

```bash
ffmpeg -i output.mp4 -filter_complex "[0:v]setpts=PTS/1.1[v];[0:a]atempo=1.1[a]" -map "[v]" -map "[a]" output-fast.mp4
```
